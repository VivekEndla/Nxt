NIAT Connect AI demo prototype.
Open index.html in a browser.
Features: lead intake, simulated AI analysis, ambassador matching, conversation brief, feedback/follow-up, dashboard, localStorage persistence.
The AI logic is demo/simulated. For a real OpenAI integration, create a secure backend endpoint and set window.NIAT_AI_ENDPOINT. Never place an API key in client-side code.
All data is fictional and not officially connected to NIAT.
